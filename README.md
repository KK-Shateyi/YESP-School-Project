# Youth Employment & Skills Portal (YESP)

**Connecting South African youth to employment and skills development opportunities.**

## About the Project

The Youth Employment & Skills Portal (YESP) is a web-based prototype designed to help young people in South Africa access employment opportunities and develop their skills.

The platform aims to connect youth with employers and opportunity providers offering jobs, internships, learnerships, apprenticeships, micro-gigs, and skills development programmes.

The project explores how information systems can help address youth unemployment by making opportunities easier to discover and access.

## Project Objectives

- Improve access to employment and skills development opportunities.
- Connect young people with employers and opportunity providers.
- Provide a central platform for discovering relevant opportunities.
- Simplify the process of finding and applying for opportunities.
- Support the review and approval of opportunity listings.

## Key Features

- **User registration and login:** Provides access to the platform's user functionality.
- **Youth profiles:** Allows young people to create profiles containing relevant information.
- **Opportunity listings:** Displays available employment and skills development opportunities.
- **Search and filtering:** Helps users find opportunities relevant to their interests and needs.
- **Opportunity submissions:** Allows opportunity providers to submit listings for review.
- **Administrative approval:** Supports reviewing, approving, or rejecting submitted opportunities.
- **Application access:** Enables young people to view opportunities and access the relevant application process.

*Note: Features listed above should be checked against the final implemented prototype.*

## Technology Stack

## Project Status

**Status:** Academic prototype

YESP was developed as part of a university project focused on applying project management and information systems concepts to a real-world challenge in South Africa.

The current version demonstrates the proposed platform and its core workflows. Further development, testing, security improvements, and user validation may be required before the system could be deployed for real-world use.

## Future Improvements

Potential improvements include:

- Expanding the number of verified employers and opportunity providers.
- Improving application tracking and status notifications.
- Strengthening user verification and data protection.
- Conducting additional usability testing with young people.
- Improving accessibility and performance on entry-level smartphones.
- Expanding the platform's features based on user feedback.
